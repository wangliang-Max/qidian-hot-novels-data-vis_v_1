# 五子棋（控制台版）

一个用 Python 标准库写成的双人五子棋，10×10 棋盘，在终端里按坐标轮流落子。
原仓库 `qsxj/python-demo` 中的 `五子棋/` 子项目，已单独拆出并修好胜负判断。

## 运行

```bash
python 五子棋.py
```

只依赖标准库（`pickle`），不需要安装任何第三方包。

## 操作

| 输入 | 作用 |
|---|---|
| `行,列`（如 `3,4`） | 在坐标 (3,4) 落子，行列均为 0–9；支持中文逗号 |
| `S` | 保存当前棋局（可直接回车用默认文件名 `五子棋存档.pkl`） |
| `L` | 读取棋局（同样支持默认文件名） |
| `Q` | 退出 |

黑方先行，程序会提示当前轮到哪一方；每次落子后打印棋盘。
横、竖、两条斜线任意方向先连成 5 子即获胜。

## 本次修复的问题

- **胜负判断**：原实现要求横、竖、两条斜线四个方向同时成立，且 `count > 5`，
  实际对局几乎判不出胜。现改为「任一方向连续 5 子及以上」即胜。
- **连子计数**：原 `check_five_row` 的起止边界会多算/少算，已重写为向正反两个
  方向逐格统计。
- **输入健壮性**：坐标非数字、越界、重复落子、空输入都有提示，不再抛异常退出。
- **退出方式**：新增 `Q` 命令，`Ctrl+C` 也能正常退出。
- **存档/读档**：读取不存在的文件、损坏的存档、棋盘尺寸不符时会提示而不是崩溃。
- 开局先打印一次棋盘，读档后也会立即刷新棋盘。
